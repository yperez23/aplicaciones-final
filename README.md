# Cambios para usar geolocator

Para usar el geolocator, aparte de ver un tutorial, tuve que agregar las dependencias en el pubspec.yaml, de ahi le di permisos en el AndroidManifest.xml.

Ya que teniamos esa parte, cree otro archivo para usar el servicio de localizacion y de ahi importe el geolocator y inicialice todo.

Una vez teniendo esto, modifique la mainscreen para que apareciera el boton e importe el geolocator y sus funciones, despues con otro string hice que se presentara 
pantalla la ubicacion.
